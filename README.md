# BSIS REGISTRATION SYSTEM

## Description
The BSIS Registration System is a simple student registration webpage created using HTML and CSS. It allows users to view a registration form and see sample student information in a table.

## Requirements
- A computer or laptop
- A web browser (Google Chrome, Microsoft Edge, etc.)
- A code editor (Visual Studio Code)
- HTML and CSS files

## How to Use

1. Download or copy the project files to your computer.
2. Make sure that the HTML file and `styles.css` are saved in the same folder.
3. Open the project folder.
4. Double-click the HTML file or right-click and select "Open with Google Chrome."
5. The BSIS Registration webpage will appear.

## How to Use the Registration Form

1. Enter your Full Name in the name field.
2. Enter your Student ID.
3. Enter your Email Address.
4. Select your Year Level from the dropdown menu.
5. Click the **Register** button to submit the form.
6. Click the **Clear** button to reset the form.

## Student Information

The Student Information section displays sample student records, including:
- Student ID
- Student Name
- Year Level

## Project Files

- `index.html` – Contains the structure and content of the webpage.
- `styles.css` – Contains the design and styling of the webpage.
- `README.txt` – Contains the project description and instructions on how to use it.

## Note
This is a basic front-end registration webpage. The registration form does not yet save student information or automatically add new records to the table.
